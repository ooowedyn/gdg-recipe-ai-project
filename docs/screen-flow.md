# YUMPICK 화면 구성

## 1. 전체 화면 흐름

```txt
첫 화면
→ 촬영 화면
→ 인식 화면
→ 필터링 화면
→ 메뉴 추천 화면
→ 레시피 화면
```

추가 흐름:

```txt
첫 화면 → 사용자 정보 화면
촬영 화면 → 사용자 앨범 화면 → 인식 화면
인식 화면 → 촬영 화면 (재인식)
메뉴 추천 화면 → 메뉴 추천 재요청
레시피 화면 → 메뉴 추천 화면
레시피 화면 → 첫 화면
```

## 2. 첫 화면

### 목적

앱의 시작 화면이다. 사용자는 카메라 버튼으로 식재료 촬영을 시작하거나, 사용자 정보 화면으로 이동할 수 있다.

### 구성 요소

- 앱 이름: YUMPICK
- 로고
- 카메라 버튼
- 사용자 정보 버튼

### 예시 문구

오늘 가진 재료로 무엇을 만들까요?

### 버튼 동작

- 카메라 버튼: 촬영 화면으로 이동
- 사용자 정보 버튼: 사용자 정보 화면으로 이동

## 3. 사용자 정보 화면

### 목적

사용자가 보유한 양념, 조리 도구, 조리 기구 정보를 확인하거나 설정한다.

### 구성 요소

- 양념 종류
- 조리 도구
- 조리 기구
- 이전 버튼

### 버튼 동작

- 이전 버튼: 첫 화면으로 이동

## 4. 촬영 화면

### 목적

사용자가 식재료 사진을 직접 촬영하거나 앨범에서 사진을 선택한다.

### 구성 요소

- 카메라 화면
- 촬영 버튼
- 앨범 선택 버튼
- 촬영 안내 문구

### 안내 문구 예시

재료가 잘 보이도록 밝은 곳에서 촬영해주세요.

### 버튼 동작

- 촬영 버튼: 사진 촬영 후 인식 화면으로 이동
- 앨범 선택 버튼: 사용자 앨범 화면으로 이동

## 5. 사용자 앨범 화면

### 목적

사용자가 기기에 저장된 사진 중 식재료 사진을 선택한다.

### 구성 요소

- 앨범 목록
- 사진 선택 영역

### 동작

- 사진 선택: 선택한 사진을 기준으로 인식 화면으로 이동

## 6. 인식 화면

### 목적

AI가 인식한 식재료 목록을 사용자에게 보여주고, 사용자가 재료를 수정하거나 확정한다.

### 구성 요소

- 촬영된 사진
- 인식된 재료 목록
- 재인식 버튼
- 재료 수정 버튼
- 재료 확정 버튼

### 예시 화면 내용

인식된 식재료

- 계란
- 대파
- 양파

### 버튼 동작

- 재인식 버튼: 촬영 화면으로 이동
- 재료 수정 버튼: 인식된 재료 목록 수정
- 재료 확정 버튼: 필터링 화면으로 이동

## 7. 필터링 화면

### 목적

사용자가 추천받을 메뉴의 조건을 선택한다.

### 구성 요소

- 난이도 선택
- 조리 시간 선택
- 알레르기 또는 제외 재료 선택
- 필터 선택 버튼
- 필터 확정 버튼

### 버튼 동작

- 필터 선택 버튼: 조건 선택
- 필터 확정 버튼: 메뉴 추천 화면으로 이동

## 8. 메뉴 추천 화면

### 목적

사용자의 보유 재료와 필터 조건을 바탕으로 추천 메뉴 3개를 보여준다.

### 구성 요소

- 메뉴 카드 3개
- 음식 이미지
- 메뉴명
- 사용 식재료
- 조리 시간
- 난이도
- 추천 이유
- 레시피 재추천 버튼
- 메뉴 카드 선택 영역

### 예시 추천 카드

메뉴명: 대파계란덮밥

사용 재료:

- 계란
- 대파

조리 시간: 10분

난이도: 쉬움

추천 이유: 현재 가진 재료만으로 간단하게 만들 수 있습니다.

### 버튼 동작

- 레시피 재추천 버튼: 추천 메뉴를 다시 요청
- 메뉴 카드: 선택한 메뉴의 레시피 화면으로 이동

## 9. 레시피 화면

### 목적

사용자가 선택한 메뉴의 조리 과정을 단계별로 확인한다.

### 구성 요소

- 메뉴명
- 필요한 재료
- 조리 시간
- 난이도
- 스크롤 형식의 단계별 조리 과정
- 간단한 요리 팁
- 뒤로가기 버튼
- 첫 화면으로 버튼

### 예시 화면 내용

메뉴명: 대파계란덮밥

필요한 재료:

- 계란
- 대파
- 밥

조리 과정:

1. 대파를 송송 썬다.
2. 계란을 풀어둔다.
3. 팬에 대파를 볶는다.
4. 계란을 넣고 익힌다.
5. 밥 위에 올려 완성한다.

### 버튼 동작

- 뒤로가기 버튼: 메뉴 추천 화면으로 이동
- 첫 화면으로 버튼: 첫 화면으로 이동
