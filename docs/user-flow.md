# YUMPICK 사용자 흐름

## 1. 사용자 상황

사용자는 냉장고에 식재료가 있지만 어떤 요리를 만들 수 있는지 바로 떠올리지 못한다. 직접 유튜브나 검색창에 재료명을 입력하는 대신, 앱을 통해 현재 가진 재료로 만들 수 있는 요리를 추천받고자 한다.

## 2. 기본 사용자 흐름

1. 사용자가 YUMPICK 앱을 실행한다. (첫 화면)
2. 카메라 버튼을 눌러 촬영 화면으로 이동한다.
3. 식재료 사진을 직접 촬영하거나, 앨범 선택 버튼으로 사용자 앨범 화면에서 사진을 고른다.
4. 앱이 사진 속 식재료를 인식하여 인식 화면에 리스트로 표시한다.
5. 사용자는 식재료 리스트를 확인한다.
6. 잘못 인식된 재료가 있으면 수정하고, 누락된 재료가 있으면 추가한다.
7. 인식 결과가 부정확하면 재인식 버튼으로 촬영 화면으로 돌아가 다시 촬영한다.
8. 사용자는 재료 확정 버튼을 눌러 최종 식재료 리스트를 확정한다.
9. 필터링 화면에서 난이도, 조리 시간, 알레르기 또는 제외 재료 조건을 선택한다.
10. 필터 확정 버튼을 누르면 앱이 보유 재료와 필터 조건을 바탕으로 추천 메뉴 3개를 보여준다.
11. 추천 결과가 마음에 들지 않으면 레시피 재추천 버튼으로 다시 요청한다.
12. 사용자는 추천 메뉴 카드 중 하나를 선택한다.
13. 앱은 선택한 메뉴의 조리 과정을 단계별로 레시피 화면에 보여준다.
14. 사용자는 단계별 레시피를 보며 요리를 진행한다.

## 3. 부가 흐름

- 첫 화면에서 사용자 정보 화면으로 이동해 보유한 양념, 조리 도구, 조리 기구를 확인하거나 설정할 수 있다.
- 레시피 화면에서 뒤로가기 버튼으로 메뉴 추천 화면으로 돌아가 다른 메뉴를 선택할 수 있다.
- 레시피 화면에서 첫 화면으로 버튼을 눌러 처음부터 다시 시작할 수 있다.

## 4. 핵심 흐름 요약

```txt
사진 입력
→ 식재료 인식
→ 식재료 리스트 확인
→ 재료 확정
→ 필터 조건 선택
→ 메뉴 추천
→ 레시피 상세 확인
→ 요리 진행
```

## 5. 예시 시나리오

사용자가 냉장고에서 계란, 대파, 양파를 꺼내 사진을 찍는다.

앱은 사진을 분석하여 계란, 대파, 양파를 인식한다.

사용자는 인식된 재료 리스트를 확인하고, 잘못된 재료가 없으면 재료를 확정한다.

필터링 화면에서 난이도 쉬움, 조리 시간 15분 이내 조건을 선택하고 필터를 확정한다.

앱은 대파계란덮밥, 계란국, 양파계란볶음과 같은 한식 메뉴 3개를 추천한다.

사용자가 대파계란덮밥을 선택하면, 앱은 필요한 재료와 조리 과정을 단계별로 보여준다.

## 6. MVP에서 제외하는 흐름

다음 기능은 MVP 이후 확장 기능으로 분리한다.

- 냉장고 실시간 스캔
- 사용자 취향 기반 추천
- 보유 양념 자동 반영
- 조리 도구 자동 반영
- 유통기한 관리
- 장보기 목록 생성
