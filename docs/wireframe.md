# YUMPICK 앱 와이어프레임 문서

## 1. 앱 개요

YUMPICK은 사용자가 식재료 사진을 촬영하거나 앨범에서 선택하면, AI가 사진 속 식재료를 인식하고 해당 재료로 만들 수 있는 메뉴를 추천하는 앱이다.

사용자는 인식된 재료를 확인하고 수정한 뒤, 난이도와 조리 시간 등의 조건을 선택하여 추천 메뉴를 받을 수 있다. 추천된 메뉴를 선택하면 단계별 레시피 화면에서 조리 과정을 확인할 수 있다.

---

## 2. 디자인 방향

### 색상

* 연한 노랑
* 갈색 계열
* 따뜻하고 귀여운 음식 앱 분위기

### 디자인 스타일

* 클로드 디자인 기반
* 피그마 또는 HTML 형태로 정리 가능
* 피그마는 시안 공유용, HTML은 프론트 구현 참고용으로 사용

### 개발 환경

* 앱: React 기반 프론트엔드
* 서버: Python + FastAPI

---

## 3. 전체 사용자 흐름

```txt
첫 화면
→ 촬영 화면
→ 인식 화면
→ 필터링 화면
→ 메뉴 추천 화면
→ 레시피 화면
```

추가 흐름:

```txt
첫 화면 → 사용자 정보 화면
촬영 화면 → 사용자 앨범 화면 → 인식 화면
인식 화면 → 촬영 화면
메뉴 추천 화면 → 메뉴 추천 재요청
레시피 화면 → 메뉴 추천 화면
레시피 화면 → 첫 화면
```

---

## 4. 화면별 와이어프레임

## 4-1. 첫 화면

### 화면 목적

앱의 시작 화면이다. 사용자는 카메라 버튼을 눌러 식재료 촬영을 시작하거나, 사용자 정보 화면으로 이동할 수 있다.

### 화면 구성 요소

* 앱 이름: YUMPICK
* 로고
* 카메라 버튼
* 사용자 정보 버튼

### 버튼 동작

| 버튼        | 동작             |
| --------- | -------------- |
| 카메라 버튼    | 촬영 화면으로 이동     |
| 사용자 정보 버튼 | 사용자 정보 화면으로 이동 |

---

## 4-2. 사용자 정보 화면

### 화면 목적

사용자가 보유한 양념, 조리 도구, 조리 기구 정보를 확인하거나 설정하는 화면이다.

### 화면 구성 요소

* 양념 종류
* 조리 도구
* 조리 기구
* 이전 버튼

### 버튼 동작

| 버튼    | 동작        |
| ----- | --------- |
| 이전 버튼 | 첫 화면으로 이동 |

---

## 4-3. 촬영 화면

### 화면 목적

사용자가 식재료 사진을 직접 촬영하거나 앨범에서 사진을 선택할 수 있는 화면이다.

### 화면 구성 요소

* 카메라 화면
* 앨범 선택 버튼
* 촬영 버튼

### 버튼 동작

| 버튼       | 동작                 |
| -------- | ------------------ |
| 촬영 버튼    | 사진 촬영 후 인식 화면으로 이동 |
| 앨범 선택 버튼 | 사용자 앨범 화면으로 이동     |

---

## 4-4. 사용자 앨범 화면

### 화면 목적

사용자가 기기에 저장된 사진 중 식재료 사진을 선택하는 화면이다.

### 화면 구성 요소

* 앨범 목록
* 사진 선택 영역

### 버튼 동작

| 동작    | 결과                      |
| ----- | ----------------------- |
| 사진 선택 | 선택한 사진을 기준으로 인식 화면으로 이동 |

---

## 4-5. 인식 화면

### 화면 목적

AI가 인식한 식재료 목록을 사용자에게 보여주고, 사용자가 재료를 수정하거나 확정할 수 있는 화면이다.

### 화면 구성 요소

* 촬영된 사진
* 재료 목록
* 재인식 버튼
* 재료 수정 버튼
* 재료 확정 버튼

### 버튼 동작

| 버튼       | 동작           |
| -------- | ------------ |
| 재인식 버튼   | 촬영 화면으로 이동   |
| 재료 수정 버튼 | 인식된 재료 목록 수정 |
| 재료 확정 버튼 | 필터링 화면으로 이동  |

---

## 4-6. 필터링 화면

### 화면 목적

사용자가 추천받을 메뉴의 조건을 선택하는 화면이다.

### 화면 구성 요소

* 난이도 선택
* 조리 시간 선택
* 알레르기 또는 제외 재료 선택
* 필터 선택 버튼
* 필터 확정 버튼

### 버튼 동작

| 버튼       | 동작            |
| -------- | ------------- |
| 필터 선택 버튼 | 조건 선택         |
| 필터 확정 버튼 | 메뉴 추천 화면으로 이동 |

---

## 4-7. 메뉴 추천 화면

### 화면 목적

사용자의 보유 재료와 필터 조건을 바탕으로 추천 메뉴 3개를 보여주는 화면이다.

### 화면 구성 요소

* 메뉴 카드 3개
* 음식 이미지
* 음식 사진
* 조리 시간
* 식재료
* 레시피 재추천 버튼
* 메뉴 카드 선택 영역

### 버튼 동작

| 버튼         | 동작                  |
| ---------- | ------------------- |
| 레시피 재추천 버튼 | 추천 메뉴를 다시 요청        |
| 메뉴 카드      | 선택한 메뉴의 레시피 화면으로 이동 |

---

## 4-8. 레시피 화면

### 화면 목적

사용자가 선택한 메뉴의 조리 과정을 단계별로 확인하는 화면이다.

### 화면 구성 요소

* 스크롤 형식의 레시피
* 단계별 조리 과정
* 뒤로가기 버튼
* 첫 화면으로 버튼

### 버튼 동작

| 버튼        | 동작            |
| --------- | ------------- |
| 뒤로가기 버튼   | 메뉴 추천 화면으로 이동 |
| 첫 화면으로 버튼 | 첫 화면으로 이동     |

---

## 5. 핵심 데이터 흐름

```txt
사진 입력
→ 식재료 인식
→ 식재료 리스트 생성
→ 사용자 재료 수정
→ 재료 확정
→ 필터 조건 선택
→ 메뉴 추천
→ 레시피 상세 조회
→ 단계별 레시피 출력
```
